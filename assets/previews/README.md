# CSS Previews

Reference renders of `squarespace/custom-css.css` applied to sample elements,
so you can see what the Custom CSS pack does before pasting it into Squarespace
(Design > Custom CSS).

- `custom-css-desktop.png` — 1280px wide
- `custom-css-mobile.png` — 375px wide (phone)

These are generated previews, not the live site. Regenerate them after changing
the CSS. Note: on the real site, mobile layout is handled by Squarespace's Fluid
Engine; these images show the *styling* (colours, fonts, buttons, inputs) the CSS
carries through, not Squarespace's own responsive reflow.
